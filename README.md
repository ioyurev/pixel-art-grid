# 🧵 Схема для вышивания (Pixel Art Grid)

Интерактивное веб-приложение для автоматического преобразования пиксель-арта в размеченную схему для вышивания крестом с символьной сеткой и подбором палитры.

## 🚀 Демо
Приложение доступно онлайн: [https://ioyurev.github.io/pixel-art-grid/](https://ioyurev.github.io/pixel-art-grid/)

## ✨ Возможности
- 📁 Загрузка собственных пиксельных изображений или встроенных образцов.
- 📐 Настройка физического размера: калибровка ячейки (мм) и итоговой ширины (мм).
- 🔣 Отображение символов и нумерации по осям (крупная сетка каждые 10 ячеек).
- 🎨 Автоматическое извлечение и отображение палитры цветов.
- 💾 Экспорт:
  - Векторный SVG
  - Растровый PNG (300 DPI)
  - Оптимизированная печать (A4 / многостраничная)

## 🛠️ Стек
- Чистый HTML5 / CSS3 / JavaScript (ES6+) без внешних зависимостей.
- Деплой через GitHub Pages (GitHub Actions).
